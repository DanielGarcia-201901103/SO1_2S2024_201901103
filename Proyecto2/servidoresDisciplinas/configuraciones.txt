6. Using Docker Compose (Optional)
If you find yourself needing to manage multiple containers frequently, consider using Docker Compose. 
With Docker Compose, you can define all your containers in a single docker-compose.yml file. Here’s a simple example:

version: '3'
services:
  app1:
    image: myapp:latest
    container_name: myapp_container1

  app2:
    image: myapp:latest
    container_name: myapp_container2

  app3:
    image: myapp:latest
    container_name: myapp_container3

To start all containers defined in the docker-compose.yml, run:
docker-compose up -d
