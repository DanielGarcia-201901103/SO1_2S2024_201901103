3. Despliegue de Grafana y Configuración de Dashboards
Grafana se utilizará para mostrar los datos almacenados en Redis y las métricas de Prometheus.

Instalación de Grafana con Helm
Usaremos Helm para simplificar el despliegue de Grafana en Kubernetes.

helm repo add grafana https://grafana.github.io/helm-charts
helm repo update
helm install grafana grafana/grafana --namespace monitoring --create-namespace \
  --set adminUser=admin,adminPassword=admin \
  --set service.type=ClusterIP
